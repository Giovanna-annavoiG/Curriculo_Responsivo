# 🚀 Currículo Digital Responsivo

## 📖 <Sobre o Projeto>
Este repositório contém o código-fonte de um currículo digital prático e 100% responsivo[cite: 1, 4]. O objetivo principal desta aplicação web é apresentar minha trajetória profissional como Desenvolvedora Web atuando em Santos, São Paulo[cite: 4]. A interface estrutura de forma semântica e acessível o meu resumo profissional, além de listar minhas experiências atuando como Representante de Desenvolvimento de Vendas na Helping Hand Negócios e no Estágio de Telemarketing na GKB[cite: 4]. O projeto também documenta minha formação acadêmica na Fatec Baixada Santista, Senai Santos e Etec Dra Ruth Cardoso, além de mapear graficamente minhas habilidades em ferramentas como Figma, React e JavaScript[cite: 4]. A estilização e o layout foram arquitetados para garantir uma visualização perfeita em diferentes resoluções e dispositivos[cite: 2, 5].

## 🛠️ <Tecnologias Utilizadas>
* A estruturação semântica do conteúdo e a importação de fontes externas foram desenvolvidas utilizando HTML5[cite: 4].
* A estilização completa, utilizando o padrão de variáveis para cores primárias e secundárias, foi construída com CSS3[cite: 1, 5].
* A responsividade do layout foi garantida pela aplicação rigorosa de Media Queries no CSS, adaptando a interface para resoluções de tela de até 780px, 425px e 375px[cite: 2].
* A tipografia principal adotada para o projeto foi a fonte 'Oswald', importada diretamente do Google Fonts[cite: 4, 5].

## ⚙️ <Pré-requisitos e Como Executar>
Por se tratar de uma aplicação client-side estática nativa, não é necessária a instalação de dependências, gerenciadores de pacotes ou builds de compilação.

1. Clone este repositório em sua máquina local utilizando o comando:
   `git clone https://github.com/Giovanna_annavoiG/nome-do-repositorio.git`
2. Acesse o diretório do projeto através do seu terminal ou gerenciador de arquivos.
3. Dê um duplo clique no arquivo `index.html`[cite: 4] para abri-lo automaticamente em seu navegador web padrão, ou utilize a extensão Live Server em seu editor de código.
